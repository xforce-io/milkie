# #259–#261 验收入口

## 设计事实源

- [#259](../../../../docs/design/259-checkpoint-resume.md)：版本化不透明 ID 精确定位已存快照，无存储不返回误导性 ID。
- [#260](../../../../docs/design/260-resume-lifecycle.md)：每次恢复新 runId，记录 previousRunId/resumedFromCheckpointId 和完整终态。
- [#261](../../../../docs/design/261-stop-result-propagation.md)：共享结果投影，子工具返回 AgentResult，原文字在 output。
