# 名词表

| 规范名 | 一句话定义 | 禁止别称 |
|---|---|---|
| 上下文预算 | 单次模型请求可使用的输入 token 上界及其区域分配和降级规则。 | token 限制、上下文窗口 |
| 上下文区域 | 按来源、稳定性和降级规则划分的模型输入组成部分。 | prompt 分区、记忆层 |
| 模型投影 | 原始运行时数据为进入一次模型请求而生成的、有界且可追踪的表示。 | 摘要、裁剪文本 |
| 证据引用 | 指向 Trace、Object Store 或 checkpoint 中原始数据的稳定标识，用于审计和回放。 | 链接、来源 |
| AgentResult | 一次执行返回的结构化结果，包含停止原因、部分完成标记及已登记产物等字段。 | — |
| checkpointId | 标识一份执行状态快照、供恢复接口定位的标识。 | — |
| stopReason | 表示执行循环为何停止的结构化字段，独立于任务是否完成。 | — |
| partial | 表示执行结果是否为部分结果的标记，有交付合同时按其完整性判定。 | — |
| artifacts | 执行结果中已登记产物及其定位信息的集合。 | — |
| resume | 从已保存的执行状态快照恢复执行的接口。 | — |
| 功能地图 | 按用户能力列出入口、行为、验证方法和已知缺口的仓库内目录。 | feature maps、feature map |
| resumedFromCheckpointId | 恢复执行开始事件中标识本次采用的确定快照的字段。 | — |
| 执行上下文 | milkie 持久保存的连接、工作目录、专用配置目录、专用会话目录和原生会话关联，以独立标识供宿主续接。 | — |
| 专用配置目录 | 宿主为一次 CLI 执行准备的配置与登录材料目录。milkie 不复制凭据。 | CLI home、登录目录 |
| 专用会话目录 | 宿主为一次 CLI 执行准备的原生会话目录。续接只认已关联的那一份会话。 | 会话库、最近会话 |
| 原生会话 | 外部 agent CLI 自身保存并按精确标识续接的对话记录。 | — |
| 执行记录 | 一次统一 SDK 请求的状态、结果及所属执行上下文关联。 | — |
| 宿主工具 | 宿主登记名称、说明和输入约束后，由宿主自己执行并返回结果的工具。milkie 只转发调用。 | 插件、内置工具 |
| 工具调用记录 | 一次宿主工具调用的稳定标识、所属执行与上下文、参数和结果状态。 | 原始事件、日志 |
| 转发策略 | 同一轮里把宿主工具交给宿主的方式。未指定时串行；宿主也可要求并行。 | 队列、批处理 |
